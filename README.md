# MovieLense Movie Recommendation System
### HarvardX Data Science Professional Certificate - Capstone Project (PH125.9x)
**Instructor:** Prof. Rafael Irizarry

## Overview
This project builds a movie recommendation system using the MovieLense dataset, predicting user ratings with a target RMSE below 0.86490.
